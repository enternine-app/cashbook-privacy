Hapus Akun & Data

Halaman ini menjelaskan cara menghapus akun dan data Anda dari aplikasi CashBook yang dikembangkan oleh Enternine.

Cara Menghapus Akun Anda

  1. Buka aplikasi CashBook di perangkat Anda.
  2. Buka menu sidebar (ikon garis tiga di kiri atas).
  3. Pilih menu "Reset Data".
  4. Konfirmasi dengan menekan tombol "Hapus".
  5. Semua data lokal dan cloud Anda akan dihapus, dan akun akan logout otomatis.

Data yang Dihapus

Ketika Anda menghapus akun, data berikut akan dihapus secara permanen:

  • Informasi akun Google (nama, email, foto profil)
  • Data transaksi keuangan
  • Data hutang dan piutang
  • Data aset
  • Sumber dana
  • Riwayat pembayaran

Data yang Disimpan Sementara

Setelah penghapusan, data Anda akan langsung dihapus dari server kami. Tidak ada data yang disimpan lebih lama kecuali diwajibkan oleh hukum.
