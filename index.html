Kebijakan Privasi

CashBook — Terakhir diperbarui: 20 September 2026

Kebijakan Privasi ini menjelaskan bagaimana CashBook ("Aplikasi", "kami") yang dikembangkan oleh Enternine mengumpulkan, menggunakan, dan melindungi informasi Anda saat menggunakan aplikasi kami. Kami berkomitmen untuk melindungi privasi Anda dan transparan tentang data yang kami proses.

1. Informasi yang Kami Kumpulkan

CashBook adalah aplikasi pencatat keuangan pribadi. Kami mengumpulkan informasi berikut:

  • Informasi Akun Google (opsional) — Jika Anda login dengan Google, kami menerima nama, alamat email, dan foto profil Anda untuk keperluan backup data dan identifikasi akun.
  • Data Keuangan — Catatan pemasukan, pengeluaran, hutang, piutang, aset, dan sumber dana yang Anda masukkan. Data ini disimpan secara lokal di perangkat Anda dan (jika login) dicadangkan ke server kami untuk sinkronisasi.
  • Data Penggunaan — Statistik anonim tentang cara Anda menggunakan aplikasi, untuk perbaikan fitur.

2. Bagaimana Kami Menggunakan Informasi Anda

  • Menyimpan dan menampilkan catatan keuangan Anda.
  • Melakukan backup dan sinkronisasi data antar perangkat.
  • Mengirim notifikasi pengingat (jika Anda aktifkan).
  • Meningkatkan kualitas aplikasi dan pengalaman pengguna.

3. Penyimpanan dan Keamanan Data

Data keuangan Anda disimpan di perangkat secara lokal menggunakan database terenkripsi. Jika Anda login dengan Google, data juga dicadangkan ke server aman (Firebase) yang hanya dapat diakses oleh akun Anda.

Kami tidak menjual, menyewakan, atau membagikan data pribadi Anda kepada pihak ketiga untuk tujuan pemasaran.

4. Berbagi Data dengan Pihak Ketiga

Kami hanya menggunakan layanan pihak ketiga berikut:

  • Google Firebase — untuk autentikasi login dan backup data.
  • Google Play Services — untuk fitur dasar aplikasi.

Layanan ini memiliki kebijakan privasi sendiri yang dapat Anda baca di situs resmi mereka.

5. Hak Anda

Anda berhak untuk:

  • Mengakses semua data yang kami simpan tentang Anda.
  • Menghapus akun dan semua data Anda kapan saja melalui menu "Reset Data" di aplikasi.
  • Menonaktifkan backup cloud dengan tidak login ke akun Google.
  • Menghubungi kami untuk pertanyaan seputar data Anda.

6. Data Anak-anak

Aplikasi ini tidak ditujukan untuk anak di bawah usia 13 tahun. Kami tidak dengan sengaja mengumpulkan data dari anak-anak.

7. Perubahan Kebijakan

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu. Perubahan akan diumumkan di halaman ini dengan tanggal "Terakhir diperbarui".
